Crypto App — One App, Three Architectures

The same real-time cryptocurrency tracker built three ways: MVVM + Combine (SwiftUI), VIPER (programmatic UIKit with protocol-based DI) and MVVM + RxSwift. A hands-on comparison of how architecture decisions shape the codebase.

MVVM VIPER RxSwift Combine URLSession

NetworkInterchangeable — Swappable Services

A SwiftUI app where the data source switches between a live API and local mock JSON at runtime through a single NetworkService protocol — without touching the presentation layer. Constructor-based dependency injection, async/await and loose coupling for testability.

SwiftUI Protocol-Oriented async/await Dependency Injection

Instagram Clone — Native iOS + Android

Swift Java / Kotlin Firebase Core Data

Trace-Driven Cache Simulator

A 4-way set-associative cache simulator in C. It collects live 64-bit addresses from running Windows processes and parses them into Tag / Index / Offset to study hardware–software interaction. Computer Architecture capstone.

C x86-64 Cache / Memory Makefile · MinGW

Game Development

Built on Apple's native game stack

As an iOS developer, my games run on SpriteKit and GameplayKit — custom rigid-body physics, collision filtering with bit masks, real-time vector math and scene lifecycle management, bridged into UIKit through an SKView.

Angry Birds Clone — SpriteKit

A physics-based slingshot game. A GameViewController downcasts the root view to an SKView to bridge UIKit and the SpriteKit render loop. Finger drag is converted to launch impulse with vector math; SKPhysicsBody drives mass, gravity and rotation; bitwise category masks handle collision filtering via delegate callbacks. Continuous velocity monitoring auto-resets the scene and tracks score.

SpriteKit GameplayKit SKPhysicsBody UIKit Swift

SpriteKit LibGDX Physics & Collision Swift Java
